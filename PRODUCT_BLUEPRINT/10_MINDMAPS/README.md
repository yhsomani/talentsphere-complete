# Mind maps

Start at [00_MASTER_MINDMAP.md](00_MASTER_MINDMAP.md). Maps render as Mermaid on GitHub. Domain maps (`01`-`08`) are generated from the module specs and list every sub-module and feature; cross-cutting maps (`11`-`19`) are generated from the section structure of the other documents.

These maps show the **intended** product. The map of what the code actually contains is [`project-mindmap/`](../../project-mindmap/master/MASTER_PROJECT_MINDMAP.md); the [documentation map](../../project-mindmap/DOCUMENTATION_MAP.md) explains how the two relate.
