## 1. Method

1. **Inventory.** All `git ls-files '*.md'`: 280 files. Each file was split into content units: paragraphs, list items, table rows (separator rows skipped) and fenced code blocks, plus heading sections. There were 111,991 units and 10,066 sections.
2. **Normalisation.** For comparison only, the text was lower-cased, Markdown punctuation and link targets removed, and whitespace collapsed. Source files were never rewritten to normalise them.
3. **Exact and formatting-only groups.** Units of at least 80 normalised characters (66,977 units) and sections of at least 200 characters were grouped by normalised text. A group whose raw text is byte-identical is **exact**; otherwise it is **formatting-only**.
4. **Near-duplicate and partial overlap.** Units of at least 120 characters (44,083) were compared by word 4-gram Jaccard similarity (MinHash LSH, 32 hashes, 8 bands, then exact Jaccard). Similarity ≥ 0.8 is **near-duplicate**; 0.6 to 0.8 is **partial overlap**.
5. **Contradictory copies.** Rows that carry the same registry ID (`F-`, `BR-`, `J-`) in `SSOT.md`, the registries and `MASTER_SYSTEM_MODEL.md` were compared by ID (§5).
6. **Disposition.** Each group got one code (§3) from the trees its copies live in, and every living-document group was then read by hand. Similar titles or topics were never treated as duplicates.
7. **References.** Every relative Markdown link and `#anchor` in every file was resolved, and backticked repository paths in living documents were checked against the tree.

Living documents are everything except `docs/archive/`, `docs/history/`, `docs/reports/`, `docs/blueprint/`, `.agents/` and `.claude/skills/`. Those trees are dated or frozen records, unratified proposals, or per-tool installs.
