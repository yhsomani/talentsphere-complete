# Evidence Register

The full register is [`EVIDENCE_REGISTER.csv`](EVIDENCE_REGISTER.csv): **2,711 rows** for 2,632 nodes (id, type, name, file, line, symbol, status, confidence, linked test files, notes). Machine-readable with full properties: [`../master/MASTER_PROJECT_GRAPH.json`](../master/MASTER_PROJECT_GRAPH.json).

## Evidence rules

1. A node exists only if a file location was found for it (route registration line, export, `CREATE TABLE`, `<Route>`, test title, workflow file).
2. A relationship exists only if a source construct implies it (call, import, SQL verb, JSX link, `parse(...)`). The edge's `file`/`line`/`note` say which.
3. Status is derived from structure, never from documentation (documented F-/J-/BR- nodes carry their documented status separately and are flagged where code disagrees). `HIGH` = source evidence plus a passing executed test: the journey's own e2e test passed, or every executed test file linked to the node passed (the link is path-level: a test that names the route or function, not an assertion-level trace). `MEDIUM` = supported by source. `LOW` = inferred.
4. Where the scan cannot tell, the node says `UNKNOWN` or the note says "not derivable" instead of a guess.
