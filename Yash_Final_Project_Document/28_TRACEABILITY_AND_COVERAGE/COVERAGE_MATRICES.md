# Coverage Matrices: AC to TEST, BR to AC to TEST, per-feature AC counts

Doc ID: TRC-COV - Owner: QA Architect with Documentation Architect - Version 1.0 - Status: Draft - Date 2026-10-25 - Relates: TRC-01, QA-CAT, QA-CAT-R2, BR-REG, PCAP-01, REVW-17, REVW-36

**Relationship statement:** this file **supersedes nothing**. It supplements `AC_TEST_TRACEABILITY_MATRIX.md` (row-per-AC list, authored separately) with the business-rule chain, per-feature counts, tiering, blocker lists and the method. It is a derived mechanical audit; where it disagrees with a source table, the source table wins. Counts are valid for the files as read on 2026-10-25; other editors changed documents concurrently, so re-run the script (section 9) instead of trusting stale numbers.

## 1. Method

- Script: Python 3, regex over Markdown tables, source in section 9. Definition position = first cell of a table row.
- **AC defined:** first cell `AC-dd-ff-nn` in `05_*/SPEC_G1..G5` (long-form, 359) or in `16_*/ACCEPTANCE_CRITERIA_GUIDE.md` (platform `AC-00-*`, 30). Duplicated definitions are merged.
- **AC to TEST (direct tier):** the AC id appears in any cell after the first of a row in `TEST_CATALOG.md` or `TEST_CATALOG_REV2.md`, **excluding** suite-level tests (`TEST-ACC-*`, `TEST-BRU-*`). Textual match only; semantic adequacy is not judged.
- **AC to FEAT:** `AC-dd-ff-nn` belongs to `FEAT-dd-ff`. This is the same convention as the independent review; an AC filed under a different FEAT number would be missed.
- **BR to TEST:** A = a direct-tier test row cites the BR. B = an AC row that cites the BR is itself directly tested. C = the BR's FEAT column names a feature whose ACs are directly tested, but no explicit BR link exists (indirect, unproven). D = none of the above.
- **Priority and phase** come from the last two cells of the FEAT row in the capability map. Those columns are being revised under REVW-10; re-run after the capability map is regenerated from the roadmap.
- Limits: prose citations without an id, ranges (`BR-T050...T059`) and shorthand are not resolved; test relevance is not judged; nothing here shows a test exists in code.

## 4. Suite-level coverage rule

A criterion is *covered* for a Ready decision only when an individual test cites it. A criterion tied only by `TEST-ACC-*` is reported as *suite-covered* and may not be counted in the coverage headline. The suites are defined in `TEST_CATALOG_REV2.md` section 3.

"""Shared parsing for the TalentSphere documentation traceability scripts (REVW-17/36)."""
import re, pathlib, collections, json
ROOT = pathlib.Path(r"C:/Users/yashs/OneDrive/Desktop/talentsphere-complete/Yash_Final_Project_Document")
AC_RE = re.compile(r"AC-\d\d-\d\d-\d\d")
BR_RE = re.compile(r"BR-T\d{3}")
FEAT_RE = re.compile(r"FEAT-\d\d-\d\d")
TEST_RE = re.compile(r"TEST-[A-Z0-9]+(?:-[A-Z0-9]+)+")

def read(rel):
    return (ROOT / rel).read_text(encoding="utf-8", errors="replace")

def rows(rel):
    """Yield (first_cell_clean, cells, raw_line) for markdown table rows."""
    for line in read(rel).splitlines():
        if not line.startswith("|"):
            continue
        cells = [c.strip() for c in line.strip().strip("|").split("|")]
        if not cells:
            continue
        yield re.sub(r"[`*]", "", cells[0]), cells, line

def all_md():
    return sorted(p.relative_to(ROOT).as_posix() for p in ROOT.rglob("*.md"))

def load():
    D = {}
    # --- features, priority, phase (04 capability map)
    feats = {}
    micro = set()
    for c0, cells, line in rows("04_PRODUCT_CAPABILITIES/CAPABILITY_MAP_AND_FEATURE_HIERARCHY.md"):
        m = re.match(r"(FEAT-\d\d-\d\d)$", c0)
        if m and len(cells) >= 6:
            pri, ph = cells[-2], cells[-1]
            feats[m.group(1)] = {"name": cells[2][:80], "pri": pri, "phase": ph}
            for mm in re.finditer(r"(?:^|\s)\.(\d+)\s", cells[2]):
                micro.add((m.group(1), mm.group(1)))
    D["feats"] = feats
    D["micro"] = micro
    caps = set()
    for c0, cells, line in rows("04_PRODUCT_CAPABILITIES/CAPABILITY_MAP_AND_FEATURE_HIERARCHY.md"):
        if re.match(r"CAP-\d\d-\d+$", c0):
            caps.add(c0)
    D["caps"] = caps
    # --- ACs: long-form in 05 SPEC_G*, platform in 16 ACCEPTANCE_CRITERIA_GUIDE (AC-00-*)
    acs = {}  # id -> {src, text}
    for rel in all_md():
        if rel.startswith("05_FEATURE_SPECIFICATIONS/SPEC_G") or rel == "16_QA_AND_TESTING/ACCEPTANCE_CRITERIA_GUIDE.md":
            for c0, cells, line in rows(rel):
                m = AC_RE.match(c0)
                if m:
                    ac = m.group(0)
                    if ac not in acs:
                        acs[ac] = {"src": rel, "text": line}
                    else:
                        acs[ac]["text"] += " " + line
    D["acs"] = acs
    # --- BRs
    brs = {}
    for c0, cells, line in rows("06_BUSINESS_PROCESSES/BUSINESS_RULES_REGISTRY.md"):
        if re.match(r"BR-T\d{3}$", c0):
            feat_cell = cells[6] if len(cells) > 6 else ""
            brs[c0] = {"scope": cells[1] if len(cells) > 1 else "", "feat_cell": feat_cell, "line": line}
    D["brs"] = brs
    # --- tests
    tests = {}
    for tcat in ("16_QA_AND_TESTING/TEST_CATALOG.md", "16_QA_AND_TESTING/TEST_CATALOG_REV2.md"):
        if not (ROOT / tcat).exists():
            continue
        for c0, cells, line in rows(tcat):
            m = re.match(r"(TEST-[A-Z0-9]+(?:-[A-Z0-9]+)+)", c0)
            if m:
                tests.setdefault(m.group(1), {"line": line, "cells": cells, "src": tcat})
    D["tests"] = tests
    # --- other registries (first-cell definitions)
    def defs(pattern, files):
        s = set()
        for rel in files:
            for c0, cells, line in rows(rel):
                m = re.match(pattern, c0)
                if m:
                    s.add(m.group(0))
        return s
    D["inv"] = defs(r"INV-T\d{2}$", ["00_CONTROL_CENTRE/CANONICAL_INVARIANTS.md", "06_BUSINESS_PROCESSES/PRODUCT_INVARIANT_REGISTRY.md"])
    D["ff"] = defs(r"FF-\d\d$", ["00_CONTROL_CENTRE/CANONICAL_INVARIANTS.md"])
    D["bp"] = defs(r"BP-[A-Z0-9-]+$", ["06_BUSINESS_PROCESSES/BUSINESS_PROCESS_INVENTORY.md"])
    D["dt"] = defs(r"DT-\d\d$", ["06_BUSINESS_PROCESSES/DECISION_TABLES.md"])
    D["sm"] = defs(r"SM-[A-Z]+$", ["06_BUSINESS_PROCESSES/STATE_MACHINES.md"])
    D["uj"] = defs(r"UJ-\d\d$", ["02_STAKEHOLDERS_AND_USERS/USER_JOURNEYS.md"])
